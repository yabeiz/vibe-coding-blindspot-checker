# Using the name

"The Command Scale" and the level names — Note, Verse, Canon, Chronicle, Saga,
Myth — are the names of a published standard. The licences in this repository
cover the text and the code. Neither grants a right in the names: CC BY 4.0
says so in §2(b), and the Apache Licence says so in §6. This file says what we
ask instead, and it asks for very little.

## What anyone may do, without asking

Implement the scale, in any product, free or paid, with or without any code of
ours. Say what your implementation measures and which version it is against.
Quote the standard, teach it, criticise it, publish readings taken with it.
Refer to the standard by name in prose, documentation, papers and talks.

## What "conformant" means

A product may state that it is **conformant to The Command Scale v1.0** when
all of the following hold:

1. It implements the four situations named in B.2 of the version it claims —
   Request, Review, Roadblock, Question — without altering them.
2. Every credited level above the first cites the person's own words verbatim,
   and the citation is checked against the command it is credited to (§5.2).
3. It states the threshold values it uses, and those values preserve the three
   properties in §5.3: a sample floor, a crediting rate, and a gap between the
   crediting rate and the withdrawal rate.
4. Where it assesses minors, it publishes the list in §9.6.
5. It passes the cases in `conformance/` — the counting and the checks, which
   have one right answer. Where it has chosen its own threshold values under
   §5.3 it will fail the cases that turn on them, and says which and why.

A product that changes the situations, drops the citation requirement, or fails
the fixtures may still be an excellent product. It is not conformant to this
standard, and saying that it is misdescribes it to the people relying on the
claim.

## What we ask you not to do

Do not use "The Command Scale", or a name confusingly close to it, as the name
of your own product, service or organisation. Name your implementation after
yourself and say that it implements the scale.

Do not state or imply that your implementation is endorsed by, affiliated with
or certified by the publisher. Nothing here certifies anyone: the scale places,
it does not certify, and no certificate is issued (B.4).

Do not apply the conformance statement to a modified scale. If you change the
levels or the situations, you have a different scale; give it a different name
and say what it takes from this one.

## The mark

The name is used as an unregistered mark and is written **The Command Scale™**
where the mark is being asserted. It is written in full, in that spelling, as a
name rather than as a description.
