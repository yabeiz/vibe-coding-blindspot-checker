# Changelog

## 0.1.0 — 2026-10-31

First public release.

- Finds the decisions a coding agent made that the person never made and was never shown, still in the code, with file and line.
- Orders them by The Command Scale v1.0: tasks where the person's words spoke in the fewest of the four situations first, then those that reached least.
- A separate list for what the agent told them in a reply or a document and they never answered, the gravest first: money, data, access, or something sent that cannot be called back; then what would not work as they meant; then what only looks different.
- Decide page: each item is settled by the person, part by part; the agent does not settle it again.
- Reads Claude Code, Cursor, Codex, Gemini CLI and Antigravity records, and plain-text transcripts.
- Rates each session on The Command Scale and adds the ratings up across audits.
